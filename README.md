# The-Virus-2
A New Commodore 64 game made by one developer fully in assembly.

Background:
This game is a sequel to a game called the Virus which I created a few years back in 2024. That game also had a Zombie Apocalypse theme but was purely text based and written in basic.
This game is my first proper C64 game and also my first major project in assembly.
Its also the first game that I've released to the public.

:The file download contains the game in these formats:

.prg
.d64
.wav

The .WAV version can be used with a car cassette adapter for the game to be played on real hardware

The game has been tested with:

C64 PAL Vice
C64C Pal Vice
C64 NTSC
An original early PAL breadbin C64.

Programming Note:
I chose to keep the Kernal as routines Like $FFD2 And $FFF0 were very useful.
I am aware that it locks me out of the Zero page and implied addressing modes but For a First Major Project the trade off seemed worth it. 
This Game took me about 3 months and took a lot of work and dedication. 
I apologize for the lack of comments in the code However i Have went back and commented some of the mode technical routines.
